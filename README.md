## 🚀 Featured Projects

### 🤖 [AgentDesk®](https://github.com/khair-eddine-ladhari/agentdesk)

**AI Agents & Workflow Automation**

A full-stack AI workspace assistant featuring a six-agent LangGraph architecture for chat, RAG, structuring, actions, summarization, and shopping.

Designed with a human-in-the-loop approval workflow so AI-proposed actions require explicit confirmation before execution.

Includes a CrewAI-powered shopping agent for product discovery and comparison.

**Tech Stack**

`Next.js` `Express` `FastAPI` `LangGraph` `CrewAI` `Groq` `Pinecone` `MongoDB`

---

### 📚 [DocChat®](https://github.com/khair-eddine-ladhari/learning-ai-assistant)

**AI & Document Intelligence**

An AI-powered content moderation pipeline using multimodal analysis to compare product descriptions against images.

The system detects potentially misleading listings and uses deterministic application logic for final moderation decisions.

**Tech Stack**

`FastAPI` `CrewAI` `Gemini` `Express` `MongoDB` `Pillow`
