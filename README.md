## 🚀 Featured Work

### [AgentDesk®](https://github.com/khair-eddine-ladhari/agentdesk) — AI Agents & Workflow Automation
A full-stack AI workspace assistant with a 6-agent LangGraph router (chat, RAG,
structuring, action, summarize, shopping). Every AI-proposed action (emails,
tasks, meetings) goes through an approve-before-execute flow — nothing gets
sent or created without explicit human approval. Includes a CrewAI-based
shopping agent that searches and compares products across Amazon, eBay, and
Walmart via SerpApi.

`Next.js` `Express` `FastAPI` `LangGraph` `CrewAI` `Groq` `Pinecone` `MongoDB`



---

### [DocChat®](https://github.com/khair-eddine-ladhari/product_detection) — AI & Document Intelligence
An e-commerce content-moderation pipeline where a multimodal AI agent
cross-checks listing text against the actual image, catching sellers who hide
restricted items (like weapons) behind misleading titles. Only code — never
the LLM — decides the final moderation status, keeping the system's
consequential decisions deterministic and auditable.

`FastAPI` `CrewAI` `Gemini` `Express` `MongoDB` `Pillow`



---
